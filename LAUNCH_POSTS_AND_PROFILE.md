## 💬 5. Reddit Post (r/webdev, r/reactjs, r/SideProject)
> *Title:* **I rebuilt classic Ludo with React 19, WebRTC Voice Chat, and modern glassmorphism (Free & Open Source)**

```markdown
Hey everyone! 👋

I wanted to share a project I've been working on: **LUVDO** — a modern, ad-free, aesthetic reimagining of classic Ludo with real-time multiplayer and low-latency voice chat.

### 💡 Why I built it:
Most mobile Ludo games (like Ludo King) are full of invasive ads, casino-style popups, and abrasive sound effects. I wanted to build something clean, elegant, and social that runs instantly on both desktop and mobile without requiring app store downloads or sign-ups.

### 🛠️ Tech Stack:
- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Canvas Confetti
- **Backend:** Node.js, Express, Socket.io (WebSocket game state machine)
- **Audio:** Native WebRTC PeerConnection for low-latency peer-to-peer voice
- **Mobile Native:** Capacitor 7 for native Android builds

### 🎯 Key Engineering Challenges Solved:
1. **Dynamic Local-First Viewport:** In Ludo, players are assigned different colors (Rose, Purple, Peach, Mint). To keep the UX intuitive, the engine mathematically maps quadrants so each connected client sees themselves at the bottom-left corner regardless of their actual track color.
2. **Multi-Token Collision Visuals:** When multiple tokens land on a safe stump or shared tile, traditional implementations simply overlay them. I built an algorithmic radial cluster offset with smooth parting transitions so every piece remains clickable and visible.
3. **Turn Freezes & Fallback:** Implemented a server-side 15-second countdown timer and instant AI bot takeovers to ensure abandoned games never freeze.

🌐 **Try it live:** [https://luvdo.onrender.com/](https://luvdo.onrender.com/)  
🐙 **Source Code:** [https://github.com/p1amrit/Luvdo](https://github.com/p1amrit/Luvdo)  
📱 **Android APK:** Direct download available in repo

Would love any constructive feedback on the UI, netcode, or gameplay feel!
```
